# Android download

The website's current Android release is stored in Firebase Storage; see
`docs/ANDROID-DOWNLOAD.md`. Local APK binaries in this directory are ignored by
Git. The local public preview can serve `Hubpas.apk` at `/downloads/Hubpas.apk`
for development, but the website button points to the verified Storage object.
iPhone users open the existing Hubpas PWA and
can add it to their Home Screen from Safari.
